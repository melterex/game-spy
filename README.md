# Game Spy

Веб-игра «Шпион» для компании игроков. Все участники получают общую тему и
слово, кроме одного игрока-шпиона. Задача обычных игроков — вычислить шпиона,
а задача шпиона — остаться незамеченным.

## Онлайн-версия

Развернутая версия игры доступна по адресу:

**[https://game-spy.duckdns.org/room/index.html](https://game-spy.duckdns.org/room/index.html)**

Для начала игры откройте адрес, зарегистрируйте аккаунт или войдите в
существующий, после чего создайте комнату либо присоединитесь к доступной.

## Правила игры

### Подготовка комнаты

1. Зарегистрируйтесь или войдите в аккаунт.
2. На странице списка комнат нажмите **«Создать комнату»**.
3. Выберите:
   - тему игры;
   - максимальное количество игроков;
   - количество ботов.
4. Создатель автоматически занимает первое место в комнате.
5. Остальные игроки выбирают комнату из списка и нажимают **«Сесть за стол»**.
6. Каждый игрок нажимает **«ГОТОВ»**.
7. Когда все участники готовы, создатель нажимает **«СТАРТ ИГРЫ»**.

Создатель комнаты также может удалить игрока из лобби. Комната рассчитана на
5–10 мест; количество ботов не может превышать доступное число свободных мест.

### Карты игроков

В начале игры каждому участнику назначается карта:

- обычный игрок видит выбранную тему и секретное слово;
- шпион видит тему, но не видит секретное слово.

Роль шпиона выбирается случайно. Игроки не видят чужие карты.

### Раунды подсказок

Игра состоит из **трёх раундов**. В каждом раунде игроки по очереди отправляют
в чат по одной подсказке, связанной со словом.

- Ход разрешен только текущему игроку.
- Остальные участники могут читать сообщения, но не могут отправить ход
  одновременно с ним.
- За один ход следует отправлять одну короткую подсказку.
- Не стоит называть слово напрямую: это облегчает задачу шпиону.
- Шпион пытается написать правдоподобную подсказку, ориентируясь на тему и
  предыдущие сообщения.

После того как все игроки завершили третий раунд, игра автоматически переходит
к голосованию. При наличии ботов их ходы выполняются автоматически.

### Голосование

На этапе голосования каждый игрок выбирает одного другого участника, которого
считает шпионом.

- За себя голосовать нельзя.
- Голос можно изменить до завершения голосования.
- Счетчик голосов отображается на карточках игроков.
- После выбора игрок нажимает **«Готов завершить»**.
- Когда все игроки подтвердили готовность, начинается короткий десятисекундный
  отсчет до завершения.
- Если кто-то отменяет готовность, стандартный таймер голосования
  восстанавливается.
- Если не все успели проголосовать или подтвердить готовность, голосование
  завершается по таймеру.

### Победа

- Если большинство голосов получает шпион, побеждают обычные игроки.
- Если большинство голосов получает обычный игрок, побеждает шпион.
- При равном количестве максимальных голосов фиксируется ничья.

После завершения голосования участники возвращаются в лобби комнаты. Можно
снова отметить готовность и начать новую игру.

## Быстрый старт для игрока

1. Откройте [онлайн-версию](https://game-spy.duckdns.org/room/index.html).
2. Нажмите **«Вход»** и выберите вкладку **«Регистрация»**, если аккаунта еще
   нет.
3. Введите логин и пароль.
4. Создайте комнату или войдите в существующую.
5. Нажмите **«ГОТОВ»** и дождитесь остальных игроков.
6. После старта следите за своей картой, очередью и таймером.
7. В свой ход отправьте подсказку в чат.
8. На голосовании выберите подозреваемого и подтвердите готовность завершить.

## Локальный запуск

### Требования

- .NET SDK 10.0 или новее;
- Git;
- доступ к NuGet для восстановления зависимостей.

Проверить установленную версию SDK:

```bash
dotnet --version
```

### Запуск приложения

Из корня репозитория выполните:

```bash
dotnet restore Game-spy.sln
dotnet run --project Web/Web.csproj
```

После запуска откройте адрес, указанный в консоли. Для стандартного профиля
разработки это:

- `http://localhost:5174`
- или `https://localhost:7244`

Главная страница приложения находится по адресу `/index.html`, список комнат —
по адресу `/room-list/index.html`, игровая комната — по адресу
`/room/index.html`.

## Основные части проекта

- [`Web`](./Web) — ASP.NET Core приложение, HTTP API, SignalR Hub и статические
  файлы интерфейса.
- [`RoomService`](./RoomService) — комнаты, лобби, игроки и настройки комнаты.
- [`GameLogic`](./GameLogic) — игровые сессии, карты, очередность ходов и
  голосование.
- [`BotService`](./BotService) — логика ботов.
- [`CardsService`](./CardsService) — темы и слова.
- [`UserManagement`](./UserManagement) — регистрация, вход и пользователи.

## Технологии

- C# и .NET 10;
- ASP.NET Core Web API;
- SignalR для обновлений комнаты в реальном времени;
- JWT-аутентификация;
- распределенный кэш для временных данных, включая OUP;
- HTML, CSS и JavaScript для клиентского интерфейса.
